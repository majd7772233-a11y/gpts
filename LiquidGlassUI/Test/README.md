# LUMEN — Liquid Glass Skill Test

موقع تجريبي يختبر تنفيذ المهارة الموجودة في [`../Liquid-Glass.md`](../Liquid-Glass.md) بالرجوع إلى [`../index.html`](../index.html).

## تشغيل المعاينة

افتح `index.html` مباشرةً في متصفح حديث. لا يحتاج الموقع إلى Node.js أو حزم بناء أو خادم Backend. يعتمد الموقع على HTML وCSS وJavaScript داخل الملف نفسه، مع خط Tajawal اختياري من Google Fonts؛ وإذا لم يتوفر الاتصال، يستخدم المتصفح خطوط النظام البديلة.

## ما الذي يمكن اختباره؟

- خلفية ضوئية سائلة متحركة تتغير مع طيف الألوان المختار.
- انعكاسات زجاجية تتبع موضع المؤشر على الأسطح.
- أسطح متعددة الأدوار: لوحة عائمة، زر بارز، وحقل إدخال غائر.
- إعدادات لتغيير لوحة الألوان وشدة الإضاءة وتشغيل/إيقاف الحركة وتتبع الانعكاسات.
- نموذج تفاعلي محلي يعرض رسالة ترحيب؛ لا يرسل البيانات إلى خادم.
- بحث يصفّي بطاقات المواد، وزر لنسخ Tokens الألوان.
- تخطيط متجاوب، قائمة تنقل للهاتف، وتفضيل تقليل الحركة.

## ملاحظات

- هذه تجربة واجهة أمامية وليست تطبيقًا بخدمة خلفية أو تسجيل دخول حقيقي.
- تأثيرات التمويه والخلفية تتدرج حسب إمكانيات المتصفح والجهاز.
- هذا المجلد مخصص لاختبار تطبيق المهارة، ولا يستبدل الملف المرجعي الأصلي.
