الاتصال وإعدادات الجلب

بدون رمز وصول تظهر المستودعات العامة للمستخدم فقط. للوصول إلى الخاصة، استخدم رمزًا محدود الصلاحيات للقراءة. الرمز لا يُحفظ محليًا ولا يدخل النسخ الاحتياطية.

استخدم صلاحيات قراءة فقط (Metadata: Read). لا تمنح Write أو Administration. عند استخدام رمز قديم أو محدود بنطاقات معيّنة، لا تمنح اللوحة سوى ما يسمح به GitHub.
