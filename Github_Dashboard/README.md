# Magd GitHub Hub — مركز مشاريع مجد

لوحة تحكم شخصية عربية لمستودعات GitHub. تجمع البحث والتنظيم ومتابعة مراحل العمل مع مستكشف تفاصيل حقيقي يعتمد على GitHub REST API.

## التشغيل
1. نزّل `Github_Dashboard/index.html` وافتحه باستخدام Edge أو Chrome.
2. اتصل بالإنترنت لجلب المستودعات وبياناتها الحية من GitHub.
3. بدون رمز، يعرض البرنامج المستودعات العامة للمستخدم المحدد.
4. للمستودعات الخاصة، استخدم Fine-grained Personal Access Token مقيدًا بالمستودعات المطلوبة وبصلاحيات قراءة فقط.
5. في بطاقة المشروع يمكنك تدوين الحالة والأولوية والفرع الحالي والمرحلة والخطوة التالية والموعد والملاحظات. هذه البيانات محلية وليست commits داخل GitHub.

## المزايا

### معلومات المستودع
- نافذة «معلومات شاملة» لكل مستودع، مع حقول Repository API المتاحة ورابط لعرض JSON الخام.
- إظهار المعرّف الرقمي وNode ID والمالك ونوع الحساب والرؤية والرخصة والمواضيع Topics والفرع الافتراضي والـ homepage وعناوين clone المختلفة.
- تواريخ الإنشاء وآخر تحديث وآخر دفع تغييرات (Push)، والنجوم وForks وWatchers وعدّاد Issues + Pull Requests.
- حالة الأرشفة والتفرّع والتعطيل، وإمكانيات Issues وWiki وDownloads وPages وDiscussions، والسماح بالتفرّع والقالب عند توافرها في استجابة API.
- روابط مباشرة إلى commits والفروع والوسوم والإصدارات والمساهمين والنشاط والتبعيات والأمان وإعدادات GitHub.

### الحجم واللغات
- عرض الحجم المبلغ عنه من GitHub بالـ KB وMB وGB وبالبايت (تحويل تقديري).
- إجمالي حجم المستودعات المعروضة في لوحة القيادة، مع MB وGB.
- جلب قائمة اللغات كاملة لكل مستودع عند فتح تفاصيله، مع عدد بايتات كل لغة ونسبتها من مجموع اللغات المصنفة، ورسوم أشرطة.
- بعد تحميل اللغات، تظهر اللغات المكتشفة في بطاقات المستودع والجدول، ويمكن البحث عنها أو استخدامها كمرشح، كما تظهر في CSV.
- تنبيه: حقل `size` في GitHub هو حجم تقديري يبلّغ عنه GitHub بالكيلوبايت؛ تحويل MB/GB يستخدم قسمة متتالية على 1024. هذا لا يساوي بالضرورة حجم ZIP أو مساحة clone، ولا يقدّر محتوى Git LFS الفعلي. مجموع أحجام المستودعات قد يحسب forks كمستودعات مستقلة.

### مستكشف الملفات
- استعراض شجرة ملفات ومجلدات المستودع مباشرة داخل نافذة التفاصيل.
- اختيار الفرع الذي تُعرض ملفاته، والتنقل بين المجلدات عبر مسارات واضحة، والبحث داخل المجلد الحالي.
- فتح الملفات النصية الصغيرة للقراءة داخل اللوحة، ونسخ محتواها، أو فتح أي ملف على GitHub.
- الملفات الثنائية أو الأكبر من 1,000,000 بايت لا يُعرض محتواها داخل اللوحة؛ بدلًا من ذلك يوفّر المستكشف رابط GitHub. وعند فتح ملف نصي كبير، يُعرض أول 50,000 حرف فقط.

### الفروع والنشاط
- قائمة الفروع مع حالة الحماية وSHA المختصر؛ تُجلب صفحات الفروع حتى 10 صفحات بواقع 100 فرع لكل صفحة.
- الوسوم Tags، وآخر Commits ورسائلها ومؤلفوها وتواريخها، وReleases، وأبرز المساهمين، وآخر GitHub Actions runs عند سماح GitHub بذلك.
- لكل قسم أخطاء منفصلة: غياب Releases أو تعطيل Actions أو نقص الصلاحيات لا يمنع عرض بقية المعلومات.

### التنظيم والإنتاجية
- البحث في الأسماء والوصف واللغة الأساسية وجميع اللغات التي تم تحليلها، والملاحظات والفروع والخطوات التالية.
- فلاتر حسب التصنيف والحالة واللغة والتثبيت والأولوية والخصوصية والأرشفة وForks والقدم والحاجة لخطوة تالية.
- أوضاع بطاقات وجدول ولوحة Kanban بست حالات مع السحب والإفلات وتغيير الحالة من قائمة.
- سجل وصول محلي، ومواعيد، ومشاريع تحتاج خطوة تالية، ومؤشرات للمستودعات القديمة.
- اختصار `Ctrl+K` لفتح الوصول السريع و`/` للانتقال للبحث.
- نسخ ملخص استئناف مشروع بصيغة Markdown لتلصقه في ChatGPT، يتضمن الرابط والفرع والحالة والأولوية والمرحلة والخطوة التالية والموعد والملاحظات.
- تصدير CSV يتضمن حجم KB وMB وGB والبايت واللغات التي تم تحليلها في الجلسة، ونسخ احتياطي JSON واستعادة/دمج التفضيلات محليًا.
- مظهر داكن وفاتح، واجهة متجاوبة، ودعم إعداد تقليل الحركة.

## صلاحيات الرمز للمستودعات الخاصة
أنشئ Fine-grained Personal Access Token واختر فقط المستودعات التي تريد الاطلاع عليها:
- `Metadata: Read-only` لبيانات المستودع واللغات.
- `Contents: Read-only` لقراءة الفروع ومحتواها والبيانات التي تتطلب الوصول إلى المحتوى.
- `Actions: Read-only` اختياري لعرض نتائج GitHub Actions للمستودعات الخاصة.
لا تمنح Write أو Administration؛ اللوحة لا تحتاج إلى تعديل المستودعات. قد يختلف ما يظهر حسب سياسة المؤسسة وصلاحيات الرمز. للمستودعات العامة، لا يلزم الرمز عادة.

## الخصوصية والتخزين
- رمز الوصول يبقى في ذاكرة الصفحة فقط، ولا يُخزَّن في localStorage ولا يضاف إلى النسخ الاحتياطية؛ بعد إعادة تحميل الصفحة أدخله من جديد للوصول الخاص.
- المفضلة والتصنيفات والحالة والأولوية والمرحلة والفرع والخطوة القادمة والملاحظات وسجل الوصول تُحفظ في `localStorage` للمتصفح الحالي.
- عند الترقية، تحاول الصفحة نقل تثبيتات وملاحظات الإصدار السابق من مفاتيح التخزين القديمة.
- النسخ الاحتياطية تتضمن ملاحظاتك المحلية؛ احفظها في مكان آمن ولا تنشرها إن كانت تتضمن معلومات خاصة.
- لا يوجد مزامنة تلقائية بين المتصفحات والأجهزة، ولا يوجد خادم أو قاعدة بيانات.
- بيانات GitHub الحية والبحث ومستكشف الملفات تحتاج إلى الإنترنت. تُخزّن قوائم المجلدات في ذاكرة الصفحة لمدة دقيقة، وتُخزّن تفاصيل المستودع لمدة خمس دقائق لتقليل طلبات API.

## حدود معروفة
- الفرع الحالي والمرحلة والخطوة القادمة ملاحظات يكتبها المستخدم؛ لا يمكن لصفحة HTML مستقلة معرفة الفرع المفتوح تلقائيًا من Android Studio أو VS Code.
- GitHub قد يعيد 403 عند نفاد حد API أو غياب الصلاحيات. التفاصيل تُجلب عند الطلب وتُخزّن في ذاكرة الصفحة خمس دقائق لتقليل الطلبات.
- بعض المستودعات لا تحتوي لغات مصنفة أو Releases أو Actions، وبعض واجهات API قد لا تكون متاحة بحسب إعدادات المستودع.
- حجم GitHub ليس قياسًا دقيقًا للملفات المحمّلة؛ استخدمه للمقارنة التقريبية لا لتقدير حجم نسخة ZIP بدقة.
