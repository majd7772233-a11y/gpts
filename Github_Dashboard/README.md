# Magd GitHub Hub — مركز مشاريع مجد

لوحة عربية تعمل كملف HTML مستقل لتنظيم مستودعات حساب GitHub، والرجوع السريع إلى المشروع مع حفظ سياق العمل محليًا.

## التشغيل
1. نزّل index.html وافتحه باستخدام Microsoft Edge أو Google Chrome.
2. اتصل بالإنترنت لجلب المستودعات من GitHub API.
3. دون رمز وصول، تظهر المستودعات العامة لحساب المستخدم المحدد.
4. للوصول إلى المستودعات الخاصة أو المستودعات التي يمكن للحساب الوصول إليها، افتح «الاتصال» وأدخل Fine-grained Personal Access Token بصلاحيات قراءة فقط، وبأقل نطاق ممكن.
5. دون عبر «بطاقة المشروع» التصنيف والحالة والأولوية والفرع الحالي والمرحلة والخطوة التالية والموعد والملاحظات.

## الميزات
- جلب جميع صفحات النتائج المتاحة من GitHub API.
- البحث في الاسم والوصف واللغة والملاحظات والفرع والمرحلة والخطوة التالية.
- فلاتر للتثبيت والحالة والأولوية والمستودعات القديمة والعامة والخاصة والمؤرشفة وForks.
- بطاقات أو جدول قابل للتمرير.
- سجل محلي لآخر المستودعات التي تم فتحها من اللوحة.
- لوحة للمواعيد القادمة والمشاريع التي تحتاج إلى خطوة تالية.
- وصول سريع عبر Ctrl+K أو زر «وصول سريع»، والضغط على / للانتقال إلى البحث.
- تصدير قائمة المستودعات إلى CSV.
- تصدير واستعادة التفضيلات والملاحظات عبر نسخة JSON.
- مظهر داكن وفاتح.
- واجهة متجاوبة ودعم تقليل الحركة.

## التخزين والخصوصية
- عند الترقية من الإصدار الأول، تحاول اللوحة نقل التثبيتات والملاحظات القديمة من مفاتيح التخزين السابقة تلقائيًا.
- بيانات المستودعات تُجلب من GitHub عند الاتصال؛ اللوحة لا تُنشئ أو تعدّل مستودعات GitHub.
- التصنيفات والحالات والأولويات والفروع والملاحظات وسجل الوصول تُحفظ في localStorage للمتصفح الحالي.
- رمز الوصول يبقى في ذاكرة الصفحة ولا يُحفظ في localStorage ولا يُصدّر في النسخ الاحتياطية. عند إعادة تحميل الصفحة ستحتاج إلى إدخاله مجددًا إذا كنت تريد الوصول إلى الخاص.
- النسخة الاحتياطية تتضمن الملاحظات؛ احفظها في مكان آمن، ولا ترفعها إلى مكان عام إذا احتوت معلومات خاصة.
- لا يوجد تزامن تلقائي بين المتصفحات والأجهزة. استخدم التصدير والاستعادة لنقل تفضيلاتك يدويًا.
- يلزم الاتصال بالإنترنت لجلب بيانات GitHub؛ أما الملاحظات المحفوظة فلا تُحذف بانقطاع الاتصال.

## حدود معروفة
- «الفرع الحالي» والمرحلة والخطوة التالية حقول شخصية يكتبها المستخدم؛ لا يمكن للصفحة المستقلة معرفة الفرع الذي فتحه المستخدم في بيئة التطوير تلقائيًا.
- ظهور المستودعات الخاصة يعتمد على صلاحيات الرمز وسياسات GitHub.
- الملف لا يحتوي خادمًا أو قاعدة بيانات، لذلك لا يوفر مزامنة مركزية بين الأجهزة.
