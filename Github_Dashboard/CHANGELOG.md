# سجل التغييرات — Magd GitHub Hub

## 3.0.0
- إضافة نافذة معلومات شاملة لكل مستودع، وقراءة بيانات Repository API الخام.
- عرض الحجم المبلغ عنه من GitHub بالـ KB وMB وGB وبالبايت، وحساب مجموع الحجم للصفحة.
- إضافة جلب جميع لغات المستودع من Languages API مع بايتات كل لغة ونسبتها، وأشرطة توضيح.
- عرض اللغات المكتشفة في البطاقات والجدول، وإضافتها للبحث والفلترة وتصدير CSV.
- إضافة معلومات المالك والرؤية والرخصة والمواضيع والفروع الافتراضية وتواريخ الإنشاء والتحديث وPush والأعداد والإعدادات المتاحة.
- إضافة قوائم الفروع والوسوم، وآخر Commits، وReleases، والمساهمين، وGitHub Actions عند توافرها.
- دعم تجميع أخطاء API لكل قسم حتى لا يمنع عدم توافر إحدى الخدمات عرض بقية التفاصيل.
- إضافة روابط إلى تبويبات GitHub المهمة، وتوسيع تصدير CSV بوحدات الحجم المتعددة.
- تحديث دليل الخصوصية والأذونات وحدود الحجم المبلّغ عنه، وتحديث الإصدار إلى 3.0.0.

## 2.2.0
- إضافة زر لنسخ ملخص استئناف المشروع بصيغة Markdown لسهولة متابعة العمل في ChatGPT.
- تضمين رابط المستودع والفرع الافتراضي والفرع اليدوي والحالة والأولوية والمرحلة والخطوة التالية والموعد والملاحظات.
- استخدام Clipboard API مع مسار احتياطي للمتصفحات التي لا تدعمها.
- تحديث الإصدار إلى 2.2.0.

## 2.1.0
- إضافة لوحة Kanban بأعمدة لحالات المشروع الست.
- دعم نقل بطاقات المشاريع بين الحالات بالسحب والإفلات.
- إضافة تغيير الحالة عبر قائمة داخل البطاقة لدعم التحكم بلوحة المفاتيح.
- تحديث الإصدار إلى 2.1.0.

## 2.0.0
- تحويل اللوحة من دليل مستودعات بسيط إلى مساحة متابعة شخصية للمشاريع.
- إضافة حقول الحالة والأولوية والفرع الحالي والمرحلة والخطوة التالية والموعد والملاحظات.
- إضافة لوحة للنظرة العامة: المستودعات المثبتة، وآخر الزيارات، والمواعيد، والمشاريع التي تحتاج إلى خطوة تالية، والمستودعات القديمة.
- إضافة بحث سريع عبر Ctrl+K واختصار / للبحث.
- إضافة عرض الجدول إلى جانب البطاقات.
- إضافة فلاتر الحالة والأولوية والقدم والأرشفة والخصوصية وForks.
- إضافة سجل وصول محلي، وتصدير CSV، ونسخ احتياطي JSON مع الاستعادة والدمج.
- إضافة المظهر الفاتح والداكن وتحسين تجاوب الهاتف ولوحة المفاتيح.
- إبقاء رمز الوصول في ذاكرة الصفحة فقط، وعدم تضمينه في النسخ الاحتياطية.
- إضافة ملف توثيق للاستخدام والخصوصية والحدود الحالية.
- الحفاظ على التثبيتات والملاحظات المخزنة محليًا في الإصدار الأول عبر ترحيل مفاتيح التخزين القديمة عند الترقية.
